# External Validation V1 — recruitment brief

## Short invitation

I am looking for two independent GIS or geospatial users to evaluate external
adoption of GeoImpact CI v1.2.0 (Report V5), an open-source research
demonstrator for comparing changes in polygon GeoJSON against declared
relationships with fixed point features. The software is the v1.2.0 tag
target `45237d7caaea2aa4b81359e46f1623918645078c`; the public adoption
instructions are frozen at repository commit
`f4745f934e7929b8b96278ba0460bc5c033c1da5`.
This is an evaluation of the software and its documentation, not a request to
endorse it. Negative feedback and cases where the tool is not useful are
valuable.

The session involves Python and GIS command-line use: installing the tagged
release, running an included example, interpreting a report, and trying one
new compatible case selected without seeing GeoImpact's result. It should take
about 60–90 minutes when compatible data are already available; preparing or
converting a case may take additional time. No confidential dataset is
required. A public dataset or non-sensitive evaluator-owned example is fine.

The purpose is to find confusing instructions, installation friction, and
interpretation risks. You are free to stop or skip a task. I will use an
anonymous record and will not publish your name, employer, private data, or a
quote without your explicit permission. Your participation does not imply
support or endorsement of GeoImpact.

## Intended recipients

- University GIS, geography, tourism, planning, or geospatial researchers
- GIS and spatial-data professionals
- Research-software engineers and data analysts who work with GeoJSON/Python
- Academic or research-software peers with practical command-line experience

The evaluator should be comfortable with basic command-line use, Python
virtual environments and package installation, and basic GeoJSON. No prior
knowledge of GeoImpact is expected. The selected new case must be a polygon
BASE/CANDIDATE pair and fixed point dependency with stable IDs; it must not be
the repository's Madrid or Sierra case. The evaluator should not already know
the intended GeoImpact output for that case.

## Contact customization checklist

Before sending, add only the meeting/contact details needed to arrange the
session. Do not make claims about external validation, scientific endorsement,
or expected successful results. Do not send this message as part of protocol
preparation; recruitment requires a separate, deliberate contact action.
